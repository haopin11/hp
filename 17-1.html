JavaScript JSON

JSON 是一种轻量级数据交换格式，用于前后端传递数据

一、什么是 JSON

// JSON 全称 JavaScript Object Notation
// 是一种文本格式，语法与 JS 对象相似，但有严格规则：
// 1. 属性名必须用双引号
// 2. 字符串必须用双引号
// 3. 不允许注释，不允许尾逗号
{ "name": "郝品", "age": 20 }

三、JSON.stringify —— 对象转字符串

var hp_str = JSON.stringify(hp_p1);   // 对象 → JSON 字符串
var hp_str2 = JSON.stringify(hp_p1, null, 2);   // 缩进 2 格美化

四、JSON.parse —— 字符串转对象

var hp_obj = JSON.parse(hp_str);   // JSON 字符串 → 对象
hp_obj.name;   // 可正常读取属性

五、fetch 加载并展示 JSON 数据

fetch("17-1-data.json")
  .then(function(hp_res){ return hp_res.json(); })
  .then(function(hp_data){ /* 展示 hp_data */ });
