Promise 与 async/await 异步演示

用「包饺子」流程演示 JavaScript 异步操作：先买原料，再并行备料，最后依次包、煮、吃

一、Promise 链式调用写法

// 每一步返回一个 Promise，用 .then 串联，Promise.all 让两件事并行 hp_buy() .then(function () { return Promise.all([ // 原料买好后，两组人同时开工 hp_dough(), // ① 和面擀皮 hp_filling() // ② 和肉馅 ]); }) .then(function () { return hp_wrap(); }) // ③ 包饺子 .then(function () { return hp_boil(); }) // ④ 煮饺子 .then(function () { return hp_eat(); }) // ⑤ 吃饺子 .catch(function (e) { console.error(e); });

二、async / await 写法

// async 函数内部用 await 依次等待，逻辑更接近同步写法 async function hp_runAsync() { await hp_buy(); // ① 先买原料 await Promise.all([ // ② 两件事并行 hp_dough(), // 和面擀皮 hp_filling() // 和肉馅 ]); await hp_wrap(); // ③ 包饺子 await hp_boil(); // ④ 煮饺子 await hp_eat(); // ⑤ 吃饺子 }
