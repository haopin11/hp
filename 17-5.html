JavaScript 两种定时器

setTimeout：延迟指定时间后执行一次；setInterval：每隔指定时间重复执行

--:--:--

一、可视化演示

① setTimeout() 延时执行一次

设定延迟时间后启动，到点只执行一次；执行前可用 clearTimeout() 取消。

毫秒
未启动
0 ms 后执行

② setInterval() 每隔一段时间重复执行

设定间隔后启动，会一直重复执行；可用 clearInterval() 暂停或停止。

毫秒
未启动
0 次
已运行：0.0 秒 最近执行：--

三、核心代码

// ① setTimeout：延迟 delay 毫秒后执行一次，返回定时器编号
var hp_timer1 = setTimeout(function () {
  hp_log('延时任务执行完毕');
}, 3000);
clearTimeout(hp_timer1); // 执行前可取消

// ② setInterval：每隔 gap 毫秒重复执行，直到被清除
var hp_timer2 = setInterval(function () {
  hp_log('周期任务第 ' + (++hp_times) + ' 次执行');
}, 1000);
clearInterval(hp_timer2); // 停止重复执行

四、两者对比

对比项 setTimeout() setInterval()
执行次数 延迟结束后只执行一次 每隔一段时间反复执行，直到被清除
语法 setTimeout(fn, delay) setInterval(fn, gap)
清除方法 clearTimeout(id) clearInterval(id)
典型应用 延时提示、防抖 debounce、页面跳转倒计时 时钟、轮播图自动播放、轮询请求、动画帧
